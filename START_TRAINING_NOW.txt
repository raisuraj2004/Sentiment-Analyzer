✨ WHAT HAPPENS WHEN YOU RUN train.py
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. Loads train_data.csv from parent directory (../train_data.csv)
  2. Maps columns: sentence→text, sentiment→target
  3. Shows dataset statistics
  4. Cleans text with 8-step preprocessing pipeline
     - Lowercasing
     - URL removal
     - Mention removal (@user)
     - Hashtag removal
     - Punctuation removal
     - Number removal
     - Stopword removal
     - Porter stemming
  5. Splits data: 80% train, 20% test
  6. Vectorizes with TF-IDF (500K features, bigrams)
  7. Trains LogisticRegression classifier
  8. Evaluates on test set
  9. Saves model.pkl and vectorizer.pkl
  10. Prints accuracy, precision, recall, F1-score
